# Meme-Check: Redaktionsspiel ZEITSPRUNG

Lernspiel für den Geschichtsunterricht (Klasse 8): Schülerinnen und Schüler analysieren ein Geschichts-Meme in fünf Stationen im Chat mit dem fiktiven Redakteur Mats Winter. Am Ende entsteht ein Zeitungsartikel.

- Eine einzige Datei: `index.html` (kein Build, keine Abhängigkeiten außer Google Fonts, funktioniert auch ohne die Schrift)
- Der Bot arbeitet mit festen Regeln, es wird keine KI benutzt und es werden keine Daten gesendet
- Ein hochgeladenes Meme-Bild bleibt im Browser

## Auf GitHub Pages veröffentlichen
1. Neues Repository anlegen und `index.html` in den Hauptordner hochladen
2. Settings → Pages → Source: „Deploy from a branch“, Branch `main`, Ordner `/ (root)`
3. Nach kurzer Zeit ist das Spiel unter `https://<benutzername>.github.io/<repository>/` erreichbar

Alle Personen und Redaktionsnamen (ZEITSPRUNG, Mats Winter) sind fiktiv.
